# 🎰 CasinoPOO

Proyecto académico desarrollado para la asignatura de **Programación Orientada a Objetos (POO)**, enfocado en la aplicación práctica de conceptos de POO mediante el desarrollo de una simulación de casino.

## 📚 Conceptos aplicados

* Clases y objetos.
* Encapsulamiento, herencia y polimorfismo.
* Colecciones.
* Patrones de diseño, incluyendo **Strategy**.
* Diagramas UML.
* Desarrollo de interfaces gráficas con **JavaFX**.
* Organización del código mediante paquetes y separación de responsabilidades.

## 🛠️ Tecnologías

* **Java 17**
* **JavaFX 17**
* **Gradle**
* **FXML**
* **UML**

## 🎯 Propósito

El proyecto tiene como finalidad reforzar los conocimientos de **Programación Orientada a Objetos**, integrando análisis, diseño, implementación y desarrollo de interfaces gráficas en una aplicación práctica.
