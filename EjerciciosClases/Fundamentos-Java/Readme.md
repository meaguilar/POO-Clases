# Fundamentos-Java

Proyecto académico orientado al aprendizaje de los **fundamentos de programación en Java**, mediante ejercicios y ejemplos prácticos desarrollados durante las clases.

## 📚 Temas

* Variables y tipos de datos.
* Operadores y expresiones.
* Estructuras condicionales.
* Ciclos y estructuras repetitivas.
* Arreglos.
* Métodos y funciones.
* Clases y objetos.
* Manejo básico de excepciones.
* Ejercicios de lógica y resolución de problemas.

## 🛠️ Tecnologías

* **Java**
* **Gradle**

## 🎯 Propósito

Reforzar los conceptos básicos de **programación en Java** mediante ejercicios prácticos que sirvan como base para el estudio posterior de Programación Orientada a Objetos y otras asignaturas relacionadas.
