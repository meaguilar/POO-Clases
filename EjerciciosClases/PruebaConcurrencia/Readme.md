# PruebaConcurrencia

Proyecto académico desarrollado para la asignatura de **Programación Orientada a Objetos (POO)**, orientado al estudio y aplicación de conceptos de **concurrencia en Java**.

El proyecto contiene ejemplos prácticos para comprender la ejecución concurrente mediante **hilos (Threads)** y la coordinación de tareas dentro de una aplicación. También incluye diagramas UML y utiliza **Gradle** para su configuración.

## 📚 Temas

* Concurrencia y paralelismo.
* Creación y ejecución de hilos.
* `Thread` y tareas concurrentes.
* Sincronización y coordinación entre hilos.
* Diagramas UML.
* Organización de proyectos Java con Gradle.

## 🛠️ Tecnologías

* **Java**
* **Gradle**
* **UML**

## 🎯 Propósito

Ejercicio práctico para reforzar los conceptos de **concurrencia y programación multihilo** dentro de la asignatura de Programación Orientada a Objetos.
