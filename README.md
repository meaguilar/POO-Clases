# Programación Orientada a Objetos

Este repositorio contiene una colección de **ejercicios, ejemplos y recursos de apoyo** desarrollados durante las clases de la asignatura **Programación Orientada a Objetos**.

Su propósito es servir como material de consulta para reforzar el aprendizaje **teórico-práctico**, facilitando la comprensión y aplicación de los conceptos fundamentales de la Programación Orientada a Objetos mediante ejercicios, ejemplos y proyectos de programación.

## 📚 Temas de estudio

A lo largo de la asignatura se abordarán los siguientes temas:

* **Introducción a los conceptos fundamentales de POO**

  * Conceptos fundamentales de la Programación Orientada a Objetos.
  * Clases y objetos.
  * Atributos y métodos.
  * Encapsulamiento.
  * Herencia.
  * Polimorfismo.
  * Abstracción.
  * Relaciones entre clases y objetos.

* **Diagramas UML**

  * Introducción al Lenguaje Unificado de Modelado (UML).
  * Diagramas de clases.
  * Representación de atributos, métodos y visibilidad.
  * Relaciones entre clases.
  * Asociación, agregación y composición.
  * Herencia y generalización.
  * Modelado de sistemas orientados a objetos.

* **Colecciones**

  * Conceptos fundamentales de colecciones.
  * Listas, conjuntos y mapas.
  * `ArrayList`, `LinkedList`, `HashSet` y `HashMap`.
  * Recorrido y manipulación de colecciones.
  * Uso de interfaces y clases genéricas.
  * Comparación y ordenamiento de objetos.

* **Patrones de diseño**

  * Conceptos fundamentales de patrones de diseño.
  * Importancia y aplicación de patrones en el desarrollo de software.
  * Patrones creacionales.
  * Patrones estructurales.
  * Patrones de comportamiento.
  * Implementación y análisis de patrones de diseño en aplicaciones orientadas a objetos.

* **JavaFX**

  * Introducción al desarrollo de interfaces gráficas con JavaFX.
  * Componentes y controles de interfaz.
  * Manejo de eventos.
  * Diseño de interfaces gráficas.
  * Organización de ventanas y escenas.
  * Integración de JavaFX con aplicaciones orientadas a objetos.

* **Patrón DAO**

  * Concepto y propósito del patrón Data Access Object (DAO).
  * Separación de la lógica de acceso a datos.
  * Implementación de interfaces DAO.
  * Clases DAO y entidades.
  * Operaciones CRUD.
  * Organización de aplicaciones mediante capas.

* **JDBC**

  * Introducción a Java Database Connectivity (JDBC).
  * Conexión de aplicaciones Java con bases de datos.
  * Configuración y gestión de conexiones.
  * Ejecución de consultas SQL.
  * `PreparedStatement` y `ResultSet`.
  * Operaciones CRUD mediante JDBC.
  * Integración de JDBC con el patrón DAO.

> **Nota:** Los ejercicios incluidos en este repositorio tienen un propósito principalmente educativo y pueden ser utilizados como referencia para el desarrollo de prácticas, actividades y proyectos de la asignatura.
